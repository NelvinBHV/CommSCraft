# Lucide icon subset

`lucide-subset.ttf` holds these glyphs of Lucide (lucide-static 1.70.0, ISC); the codepoints are those of its `font/codepoints.json`. To add an icon, cut a new subset from the same package version with the extended list and update ATTRIBUTION.md.
