# CommSCraft

Independent Rust clean-room research project aiming at full feature parity with the classic Skype for Business Windows Full Client.

**Current status:** v0.14.0 prototype developed locally; the complete source tree has not yet been imported into this GitHub repository. No working live authentication or real server interoperability is demonstrated.

The project follows Microsoft Open Specifications (including MS-SIPAE and MS-SIPREGE) and relevant IETF RFCs (including RFC 3261). Version 1.0 is gated on proven Windows Full Client feature parity.

Not affiliated with Microsoft.
